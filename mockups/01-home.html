Building intelligent techniques for more reliable software

The SODA (SOftware Debugging and Analysis) Nexus Lab develops AI-assisted software engineering techniques that help developers understand, test, debug, and improve complex software systems.

Our research brings together large language models, program analysis, software testing, and mining software repositories to address practical challenges in software quality assurance.

What we work on

🧠

AI for Software Engineering

How large language models and intelligent agents can support software development while improving correctness and trustworthiness.

🐞

Automated Debugging & Testing

Techniques for fault localization, automated repair, test generation, and program analysis.

🗄️

Mining Software Repositories

Analyzing code, commits, issues, and execution data to uncover insights for better engineering decisions.

⌨️

Intelligent Software Operations

Investigating logs, traces, and runtime data to detect, diagnose, and explain failures in complex systems.

Our approach

  • Practical — designed around real developer and industry needs
  • Evidence-driven — evaluated using realistic systems and defects
  • Trustworthy — focused on reliability, explainability, and quality
  • Collaborative — developed with academic and industry partners
