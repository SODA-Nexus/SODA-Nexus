FaR-Loc: Functionality-Aware Fault Localizations via Retrieval-Augmented Generation

IEEE Transactions on Software Engineering, 2026
Jordan Whitfield, Amara Reyes, Wei Chen
⬇ Download PDF
Abstract

We introduce a retrieval-augmented approach that leverages functionality information to localize software defects more accurately and efficiently. By retrieving semantically related code fragments and grounding a language model's reasoning in real functionality descriptions, our method reduces false positives compared to purely embedding-based baselines across five open-source benchmarks.

TRAIL: Template-preserving Rare-event Augmentation for Log-based Anomaly Detection

Preprint, 2026
Emily Sato, Amara Reyes
⬇ Download PDF
Abstract

Rare failure events are underrepresented in system logs, making them difficult for anomaly detectors to learn. TRAIL generates synthetic rare-event log sequences that preserve the structural templates of real logs, improving detection recall on infrequent failure types without degrading precision on common patterns.

Explainable Retrieval-Augmented Debugging for Large Codebases

ICSE 2026 Student Research Competition
Jordan Whitfield, Priya Kapoor, Amara Reyes
⬇ Download PDF
Abstract

We present a debugging assistant that pairs retrieval-augmented generation with structured explanations, letting developers inspect why a suggested fix location was chosen. A user study with 24 developers shows faster triage times and higher trust compared to unexplained LLM suggestions.

Mining Commit Histories for Recurring Defect Patterns

ASE 2025
Daniel Nkemelu, Amara Reyes, Sofia Martins
⬇ Download PDF
Abstract

We mine commit histories across 40 large open-source repositories to identify recurring defect patterns tied to specific code change types. Our taxonomy of patterns is used to build a lightweight static checker that flags commits with elevated defect risk before merge.

LLM-Guided Test Generation for Concurrent Systems

FSE 2025
Marcus Thibault, Ravi Hallan, Amara Reyes
⬇ Download PDF
Abstract

Testing concurrent systems requires exercising rare thread interleavings that are hard to construct by hand. We use large language models to synthesize targeted test schedules guided by static race-detection hints, uncovering 15 previously unknown concurrency bugs in evaluated projects.
