<p>Modern software systems are large, fast-changing, and increasingly hard to verify by hand. SODA Nexus exists to close that gap — building tools and techniques that help engineers find, understand, and fix defects faster, with less manual effort.</p>
<p>We treat large language models as a new kind of instrument for software engineering research: powerful, but only trustworthy when paired with rigorous program analysis and careful evaluation on real systems.</p>
<p>Our work spans automated debugging, fault localization, test generation, mining software repositories, and intelligent software operations — always grounded in problems that practicing developers actually face.</p>
